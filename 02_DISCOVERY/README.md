# 02 — PRODUCT DISCOVERY

Amac: Uygulamanin amacini, kullanicilarini, davranislarini, kurallarini ve kapsam sinirlarini teknik karar vermeden derinlemesine anlamak.

Akis: 5 genel soru -> cevaplar -> 30 soruluk iterasyonlar -> her iterasyonda sentez -> sonraki sorularin onceki ogrenimlere gore uyarlanmasi.

305 soru hedef degil, baslangic referansidir. Yeterli doygunluk daha erken veya daha gec olabilir.

Teknik sorular yasaktir: database, framework, hosting, API teknolojisi, sifreleme implementasyonu vb. bu asamaya ait degildir.
