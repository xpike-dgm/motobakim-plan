# NON-GOALS

Status: DRAFT

Bu belge urunun bilerek yapmamasi gereken davranislari ve henuz non-goal oldugu kanitlanmamis sinirlari ayirir.

## Confirmed non-goal behaviors

### NG-001 — Fabricated technical certainty
**CONFIRMED — Q035, Q041-Q044, Q075-Q079, Q095**
Dogrulanmamis technical value, maintenance interval veya sahte kesinlik uretmek hedef degildir.

### NG-002 — False definitive diagnosis
**CONFIRMED — Q023-Q024, Q035, Q056-Q058**
Evidence yetersizken definitive diagnosis veya random part replacement yonlendirmesi hedef degildir.

### NG-003 — Guaranteeing dangerous-work success / bypassing safety gates
**CONFIRMED — Q035, Q045-Q052, Q068-Q069, Q096-Q101, Q126-Q128**
Dangerous work success guarantee etmek veya critical condition unverified iken application'i acmak hedef degildir. `Professional help optional` demek safety gate optional demek degildir.

### NG-004 — Paywalling core safety / core completion / basic history / user data portability
**CONFIRMED — Q065, Q087, Q114-Q115, Q145-Q146**
Required safety info/visuals/checks, operation completion icin gereken steps, reasonable history veya user's own data export premium'a baglanmamalidir.

### NG-005 — Silent rewrite/loss of historical context
**CONFIRMED — Q042-Q043, Q059-Q060, Q073, Q095, Q137**
Guide update/recall, user correction veya ownership transfer sonrasi historical context silent overwrite/loss hedef degildir.

### NG-006 — Cross-account data mixing
**CONFIRMED — Q092, Q094-Q095**

### NG-007 — Commercial influence disguised as technical guidance
**CONFIRMED — Q085-Q088, Q095**

### NG-008 — Community content masquerading as official guidance
**CONFIRMED — Q081-Q084, Q107**

### NG-009 — Forced technical-identifier scavenger hunt as default variant flow
**CONFIRMED USER EXPECTATION — Q066-Q067**

## Boundaries, not confirmed non-goals

### Community / social layer
Community tumden kapsam disi degildir. Secondary provenance/review/moderation layer olabilir. Downstream withdrawal effects Q-0049'da aciktir.

### Service / marketplace / commercial support
Service/parts support non-goal degildir; core self-service'in yerini alamaz ve technical neutrality'yi bozamaz.

### Paid product model
Basic/reasonable history ve basic multi-bike separation core expectation'dir. Large media archive, advanced comparative analytics ve extensive collaboration premium candidate olabilir. Final price/tier/business viability secilmemistir.

### Professional/service users
Initial direct target owner'dir. Professional/service/hobby helper owner-invited collaboration participant olabilir. Ayrı professional business-management product daha sonra dusunulebilir; ilk urunun owner-first core'unu degistirmemelidir.

### International scope
Turkiye-first language/unit expectation vardir; future global scope hakkinda LOCKED karar yoktur.
