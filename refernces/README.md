# Visual Reference Assets

This directory contains the visual references and logo assets used during Phase 3 design planning.

The directory name contains a legacy misspelling (`refernces`). It is intentionally preserved at this checkpoint so
existing document links and evidence paths do not break. Do not rename or reorganize these assets without a dedicated
migration that updates and verifies every reference.

Canonical authority for whether an image is approved, supporting or historical is
`03_DESIGN/REFERENCE_INDEX.md`. Presence in this directory alone does not make an image approved.
