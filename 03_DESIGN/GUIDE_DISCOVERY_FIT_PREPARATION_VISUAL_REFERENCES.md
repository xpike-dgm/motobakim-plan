## Working Family Authority

This set authorizes the visual/interaction continuity:

AI Usta known-task entry
-> D01 task discovery
-> D02 fit/scope/trust preview
-> D03 readiness
-> application only when required conditions permit.

Bakim can enter the same trusted guide system from a relevant maintenance item/detail through an explicit `Bakimi yap` / `Rehberi ac` intent.

There is no sixth `Rehberler` bottom tab.

## D01 Authority

Working meaning:
- user can describe/find the intended task in plain language,
- a candidate guide/task can be selected,
- selection does **not** itself prove motorcycle fit or readiness.

## D02 Authority

Working meaning:
- user understands guide scope,
- motorcycle applicability is visible,
- trust/freshness can be concise with deeper detail,
- verified/applicable does not imply guaranteed success,
- application cannot proceed on unresolved fit.

The generated motorcycle/mechanical imagery is illustrative only and cannot establish real fit.

## D03 Authority

Working meaning:
- required/critical/optional preparation is distinguishable,
- relevant safety prerequisites are visible before physical work,
- one dominant start action may be used for an actually application-ready fixture.

**Critical constraint:** `Uygulamaya hazir` and an enabled `Rehberi baslat` action are valid only when all mandatory/critical conditions have actually been verified for the current context. Pending/unknown/stale/failed critical readiness must not be shown as ready.

Generated example preparation items are not technical source-of-truth. Their required/optional classification must be validated task-specific content in production.

## D04 Authority

Working meaning:
- a critical readiness hold stops application,
- the missing condition and why it matters are clear,
- remediation and recheck are explicit,
- self-assertion cannot bypass the gate,
- no `continue anyway` action exists.

## D05 Authority

Working meaning:
- teaching/reference remains accessible while physical application is unavailable,
- teaching-only is clearly labelled,
- the screen does not masquerade as numbered physical instructions,
- completion is not implied,
- recheck/re-entry remains discoverable.

## Required Brand Constraint

Canonical brand authority remains:
