Status: APPROVED WORKING DIRECTION

## Working Direction

**V10 — Signature Kavriva**

This is the approved working **anchor-screen visual direction** for Phase-3 design exploration.

It is layered on top of:
- approved working brand: `Kavriva`,
- approved working logo direction: `L05A — The Precision Fit`,
- approved working anchor UX structure: `U04 — Progressive Detail`.

## Core Visual DNA

- clean near-white / very light canvas,
- deep graphite / navy-black primary text,
- restrained electric-blue accent,
- realistic, sharp, inspection-focused photography,
- one clear physical focus annotation,
- moderate corner rounding,
- low decorative noise,
- strong typographic hierarchy,
- controlled geometric icon character,
- restrained L05A logo presence,
- deliberate technical credibility rather than racing/performance energy.

## U04 Hierarchy Remains Authoritative for the Anchor Fixture

The visual direction must preserve:
1. compact brand + motorcycle context,
2. progress,
3. step title,
4. task subtitle/context,
5. compact trust label,
6. one dominant task visual + one annotation,
7. concise instruction,
8. visible but calm critical safety meaning,
9. one flat/collapsed detail affordance,
10. one dominant completion CTA,
11. lower-emphasis visible recovery path.

No new card-stack, KPI, dashboard, tab, timeline or equal-weight secondary CTA should be introduced simply for visual styling.

## Working Visual Principles

- Primary physical task remains visually dominant.
- Brand supports the task; it does not compete with it.
- Electric blue is an accent/signature, not a fill-everything color.
- Trust remains compact and readable.
- Safety remains visible when critical but does not become a permanent alarm banner.
- Recovery remains visible but clearly secondary to normal continuation.
- Photography must make the inspected physical area easy to locate.
- UI surfaces should feel calm and precise, not industrial-cosplay, fintech-dashboard or gaming/racing.

## Important QA Constraints

### Trust / certification ambiguity
The reviewed V10 image uses shield/check-style iconography for trust and safety. This is NOT approved as final component semantics.

Future refinement must avoid implying:
- official safety certification,
- guaranteed correctness,
- guaranteed repair outcome.

Trust/provenance and safety/attention should remain semantically distinct.

### Motorcycle-specific imagery
The generated V10 image is a **visual-treatment reference only**. It is not verified imagery for a specific real motorcycle/version.

### Responsive behavior
The reviewed header is a reference composition, not a guarantee that brand + motorcycle context must remain on one line on all devices/languages.
