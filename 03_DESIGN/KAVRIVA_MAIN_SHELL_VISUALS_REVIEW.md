- general restrained line-icon character.

It does NOT approve exact icons. A single production icon family must later be normalized.

## Constraint 02 — R03 Decorative Image Is Optional Visual Treatment

A1 canonical hierarchy is:
compact context -> prompt -> two paths.

R03 includes a large motorcycle crop between context and prompt. The image is acceptable as working visual treatment because the core two-path interaction remains clear, but it is NOT added to A1 as a required structural element.

Future variants must remove/reduce the image if it pushes the two actions below comfortable visibility, reduces accessibility, or suggests technical/diagnostic evidence.

R05 gives `Katki yap` high visual weight.
