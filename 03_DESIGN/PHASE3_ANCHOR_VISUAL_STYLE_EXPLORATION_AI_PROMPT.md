## ABSOLUTE ANTI-DRIFT RULES

Visual style ugruna SUNLARI YAPMA:
- layout order'ini degistirme,
- yeni card/panel ekleme,
- mevcut block'u baska yere tasima,
- primary CTA logic'ini degistirme,
- recovery'yi equal-weight CTA yapma,
- safety'yi gizleme veya dev hero banner yapma,
- trust label'i certification badge'e cevirme,
- provenance'i default expanded yapma,
- extra explanation'i default acma,
- new tab/bottom-nav/header actions ekleme,
- dashboard/KPI/metric chips ekleme,
- carousel, tabs, timeline, stepper veya yeni interaction pattern ekleme,
- logo geometry'sini buton/card/divider sekline klonlama,
- UX'i daha "yaratici" gostermek icin element sayisini artirma.

**Her variant ayni U04 ekraninin yeniden giydirilmis hali gibi gorunmeli; baska UX ekranina donusmemeli.**

## 10 VISUAL STYLE DIRECTIONS

### V01 — Clean Precision
Aydinlik, crisp, yuksek duzen hissi. Neutral foundation, subtle technical character, minimum decoration. Generic enterprise dashboard'a donusmesin.

### V02 — Warm Technical
Ayni U04 structure, daha insani warm-neutral palette ve soft mechanical credibility. Workshop-grunge veya retro endustriyel cosplay yapma.

### V03 — Premium Consumer
Refined consumer-app polish, kaliteli typography, sakin surfaces, premium ama mesafeli olmayan karakter. Luxury lifestyle app'e donusmesin.

### V04 — Calm Safety
Safety communication cok temiz ve sakin. Alarm-red dominance yok; critical meaning net. Medical-app veya insurance-dashboard hissi yaratma.

### V05 — Visual Craft
Same hierarchy, fakat task image treatment'i daha kaliteli/immersive: crop, annotation, image contrast ve focus treatment daha güçlü. Layout degismez.

### V06 — Soft Precision
L05A'nin angular precision karakterini daha approachable surfaces ve hafif yumusatilmis UI diliyle dengele. Cocukca veya bubbly olmasin.

### V07 — Graphite Dark
Controlled dark theme. Garage/low-light use icin sakin, yuksek okunabilirlikli. Cyberpunk, neon, racing, gaming hissi yok.

### V08 — High-Legibility Field
Ayni UX hierarchy; daha okunakli type, stronger contrast, clearer action affordance ve field-use polish. Element sayisi/yerlesim mantigi degismez.

### V09 — Editorial Technical
Strong typography and disciplined spacing ile editorial kalite. Magazine layout'a donusmeden app usability korunur. Same U04 structure.

### V10 — Signature Kavriva
Kavriva icin en ayirt edilebilir fakat sade visual character adayi. L05A precision-fit ruhunu subtle olarak tasir; logo geometry clone'u veya brand-pattern kalabaligi yapmaz.
