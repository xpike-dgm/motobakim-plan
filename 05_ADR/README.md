# 05 — ARCHITECTURE DECISION RECORDS

Bu klasor teknoloji ve mimari kararlarinin nedenleriyle birlikte kalici kaydidir.

Bir teknoloji, sadece bir belgede adi gectigi icin secilmis sayilmaz. Gerekli kararlar ADR ile APPROVED/LOCKED hale gelir.

ADR'ler gecmisteki karari silmez; yeni ADR eskisini SUPERSEDED yapar.
